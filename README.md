# skills-center

药研团队「技能中心」的同事侧客户端技能(Agent Skill)。装好之后对 AI 说自然语言,就能:列出/安装/更新技能、连接技能中心、替业务技能取凭证、没权限时代提申请。全部对话在「技能清单」正源(飞书文档)里选,值只在进程里过手,不进聊天、不落文件。

## 安装

对 AI 说「装技能中心客户端」,或手动执行:

```
npx skills add https://github.com/koyurion/skills-center -y
```

更新:`npx skills update -y`。

## 谁读什么

- **同事(使用者)**:装上本技能就是全部,直接说人话。
- **技能负责人(owner)**:开权限、凭证登记/轮换/换绑/吊销、上架,不在本技能——见飞书文档「技能中心·owner 手册」。
- **想弄懂机制与接口**:见架构页《凭证管理服务架构》(向平台组索取)。

## 边界

本技能要求 agent 能访问公司内网;豆包工作·云电脑模式的云主机到不了内网,凭证技能在那边如实说不可用(不是故障)。不做:自动上架、代用户确认连接、打印或保存凭证值、未经 owner 指令开权限。

维护:koyurion(平台组)。
