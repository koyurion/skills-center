# skills-center

药研团队「技能中心」的客户端技能(Agent Skill),一个技能两种角色。装好之后对 AI 说自然语言:

- **技能使用者**:列出/安装/更新技能、连接技能中心、替业务技能取凭证、没权限时代提申请
- **技能开发者**:开文档权限、凭证登记/轮换/换绑/吊销、查账、上架

技能一律从「技能清单」正源(飞书文档)里选;值只在进程里过手,不进聊天、不落文件。

## 安装

对 AI 说「装技能中心客户端」,或手动执行:

```
npx skills add https://github.com/koyurion/skills-center -y
```

更新:`npx skills update -y`。

## 两种角色

- **技能使用者(Skill User)**:装上本技能就是全部,直接说人话。
- **技能开发者(Skill Developer)**:同样这一个技能——说「给张三开 <技能> 的权限」「把这条凭证登记进技能中心」即可,剧本在技能的「开发者」节。原飞书文档「技能中心·开发者手册」已并入(2026-10-15)。
- **想弄懂机制与接口**:见架构页《凭证管理服务架构》(向平台管理员索取)。

## 边界

本技能要求 agent 能访问 xtalpi.feishuapp.com(公网 HTTPS)——不再要求公司内网,豆包工作·云电脑模式也能用凭证技能。连接技能中心 = 用户在飞书点一次「同意」(会话凭证由飞书签发,约 2 小时),凭证只在会话内存、不落盘。不做:代用户点授权、打印或保存凭证值——登记与轮换的值命令由开发者亲手跑;权限由开发者在文档侧开。
